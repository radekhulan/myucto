# XMLZAM 1.0

Soubor `EPXSD-1.0.xsd` je oficiální schéma Exekutorské komory ČR pro
elektronickou výměnu dat mezi soudním exekutorem a plátcem mzdy podle vyhlášky
č. 394/2023 Sb.

- zdroj: `https://www.ekcr.cz/zamestnavatele/EPXSD.xsd`
- publikováno zdrojem: 23. 1. 2024
- SHA-256: `7e6f8dfc27118f9788da1a067fd55526cc5373f3b2395c81d3af822423fb7657`

Runtime schéma používá pouze po kontrole uvedeného otisku. Testovací XML musí
obsahovat výhradně syntetická data.
